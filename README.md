# Stroke Risk Prediction Analysis 

## Project Overview

According to the World Health Organization, stroke is the third-leading cause of death and disability globally, making it a major public health concern. 

This project aims to develop a machine-learning model that uses patient demographics, medical 
conditions, and lifestyle factors—including age, gender, hypertension, heart disease, 
average glucose level, BMI, and smoking status—to identify individuals who may be 
at an elevated risk of stroke.

---

## Dataset

- Source: https://www.kaggle.com/datasets/fedesoriano/stroke-prediction-dataset
- Key Variable:
  - `stroke` → indicates whether a patient had experienced a stroke
